## Como Adicionar um POP

1. Criar `architecture/<nome-em-kebab-case>.md` seguindo o template da Fase A (`06_vlaeg_protocol.md §1`)
2. Adicionar linha neste INDEX antes de commitar o código
3. Commit com mensagem: `docs(architecture): add POP <nome>`

## Status Permitidos

| Status | Significado |
|--------|------------|
| `DRAFT` | POP em elaboração, código ainda não implementado |
| `ACTIVE` | POP aprovado, módulo em produção |
| `DEPRECATED` | Módulo desativado, POP mantido para referência |
| `REFACTORING` | Módulo em processo de refatoração |
